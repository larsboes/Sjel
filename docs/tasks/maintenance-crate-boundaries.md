# Measure crate-boundary changes

## Outcome

Proposed crate moves have a measured consumer and maintenance benefit.

## Acceptance

- Identify independent consumers before proposing a split.
- Measure build time, retained artifacts and process overhead before consolidation or renames.
- Keep the root and GPUI workspaces separate unless evidence and coordination justify a change.
