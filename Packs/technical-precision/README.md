# Technical precision

A general reasoning and writing skill for research, debugging, evaluation, architecture, calculations, and technical documents. It emphasizes evidence, scope, uncertainty, and actionable conclusions.

## Use

The skill routes to short reference modules only when the task needs them. The core skill is harness-neutral and has no local account, machine, or project configuration.

## Method basis

The skill names its public references in `skills/technical-precision/References/method-basis.md`: Google technical-writing guidance, the Google SRE troubleshooting chapter, John Platt's “Strong Inference,” NASA decision analysis, and RFC 2119/8174. It does not vendor their text or code. Its actionability guidance is adapted from Sjel's `attention-control` skill; its controlled-language guidance is adapted from the sibling `asd-ste100` skill.
