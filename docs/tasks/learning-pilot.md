# Run five teach and practice pairs

## Outcome

Run five teach and practice pairs through the existing owner, with implementation and live acceptance recorded separately.

## Acceptance

- Record five teach and five practice sittings in the configured Learning Log, including an existing-note topic, a source-led topic, delayed transfer to a changed example and resumption after interruption.
- Demonstrate one real concept and learner-reviewed claim with valid metadata, provenance, Because links, paraphrase deduplication and contract-compliant placement; keep material maturity separate from learner understanding.
- Exercise prediction and check cards and one checked background-built figure in RPC; inspect the Claims Base view and figure anatomy in Obsidian, including an Anatomy html-embed.
- Record each proposed UI improvement as observed or not observed; generated notes, quiz exposure and confidence alone do not establish mastery.
