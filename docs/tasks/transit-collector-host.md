# Collect with the Mac closed

## Outcome

Run collection on an owner-controlled host and merge on wake.

## Acceptance

- The Mac stays closed for three weekdays.
- After wake, those mornings appear exactly once.
- The watch set and location routine remain on owner-controlled machines.
