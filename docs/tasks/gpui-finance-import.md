# Accept Finance import and review

## Outcome

Accept Finance import and review through the existing owner, with implementation and live acceptance recorded separately.

## Acceptance

- Select a CSV through the native picker, send contents not paths, review mapping before import and accept/reject/recategorize candidates.
- Check transfer matching, spending review, trip/reimbursement links, balance snapshots and keyboard category entry.
- Use synthetic implementation fixtures and separately record owner-approved live acceptance.
