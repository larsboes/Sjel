# Validate A2UI view documents against the registry in Rust

## Outcome

A Rust validator admits an A2UI-subset view document only when every component comes from the
registry catalog and every binding names an approved registry read route.

## Acceptance

- Define the supported A2UI subset in one schema owned by `apps/gpui/core`.
- Reject unknown components, invalid properties, write-route bindings, cycles and oversized
  documents with an error that names the failing node.
- Render source strings as escaped text; no document field is interpreted as code or instructions.
- Pass the adoption gate in [the format comparison](../../research/svelte-adaptive-ui.md#adoption-gate)
  for a synthetic list, detail and form view, saved and reloaded without a model.
