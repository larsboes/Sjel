# Permit routine overlay configuration without opening policy guards

## Outcome

Ordinary private-overlay application configuration can be maintained without repeated approval
cards. Secrets, permission policy and executable configuration remain protected.

## Decision

The operator selected scoped routine-configuration exceptions, not removal of overlay-wide
protection or the command-policy layer. Existing OS policy already permits configuration reads;
this change concerns command-policy write admission. Implementation waits for concurrent edits
to the command-policy source to settle.

## Proposed boundary

Use an explicit machine-local allowlist of ordinary configuration files below the overlay's
configuration directory. Keep the overlay protected by default. Exclusions take precedence over
an allowlist: secrets and credentials, provider and agent policy, harness configuration,
permission grants, hooks and executable configuration cannot inherit routine access. Machine
capability selection is consequential configuration and remains gated unless explicitly reviewed.
Resolve literal paths canonically; symlink escapes and changed targets gain no permission.
Do not infer safety from a filename extension or grant the entire configuration directory.

The configuration owning these grants remains protected. Direct edits retain current-read and
concurrency checks. Permission does not authorize unrelated tasks, service activation or external
effects. No configuration values or private path inventory belong in tracked documentation.

## Acceptance

- Reviewed ordinary configuration edits under explicit machine-local grants run without cards.
- Adjacent unlisted files and all excluded policy, credential and executable targets remain gated.
- Symlink escapes, path replacement and shell destination ambiguity gain no grant.
- Existing command-policy tests and installed-Pi type checks pass after concurrent changes settle.
- Reload acceptance confirms only the approved machine-local files gain write admission.

## Verification

Design recorded only. No classifier, machine grants or live permission settings changed.
