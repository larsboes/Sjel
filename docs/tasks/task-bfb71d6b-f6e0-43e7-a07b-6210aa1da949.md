# Run every service from one release build directory

## Outcome

All long-running Sjel binaries start from the shared Cargo target. The checkout's `target/`
holds no release output that a process uses.

## Acceptance

- List every launcher, service runner and resolver that names `<checkout>/target/release`,
  including `tools/lib/local-build.sh`, and point each one at `$CARGO_TARGET_DIR/release`.
- Restart each affected service and verify with `ps` that no process runs from the checkout's
  `target/`.
- Remove the checkout's `target/release` only after that check, through `sjel storage reclaim`.
  Record the free-space change.

## Evidence

On 2026-11-20, 18 binaries ran from the checkout's `target/release` (27 GB): the capability
servers, `sjel-cli` and `sjel-status`. Only `sjel-mcp` and `sjel-contain` ran from
`~/.cargo-target/release` (41 GB). `sjel storage report` protects the shared directory but
does not name the checkout's copy.
