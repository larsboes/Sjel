# Remove the replica setup tab from the Mac app

## Outcome

The Mac Setup page no longer offers Turso replica configuration, and no client code calls the
removed `sjel-status` setup routes.

## Acceptance

- Remove the Machine tab in `apps/gpui/ui/src/setup/machine.rs` and its plan, verify and apply
  calls in `apps/gpui/core/src/shell/systems_backup.rs` and `apps/gpui/core/src/setup.rs`.
- Remove `crates/setup-api` and its re-exports in `crates/status-api` when no consumer remains.
- Setup opens directly to paired devices. Check the installed app can load the pairing listener and show a one-time code.

## Evidence

The Mac app and GPUI core suites pass. A GPUI headless test mounts the pairing controls directly;
core tests cover listener decoding and the pairing payload. The LAN contract remains in `status-api`.
Live pairing in the installed app remains open.
