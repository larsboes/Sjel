# Learning

The [Learning Pack](../../Packs/learning/README.md) owns teach, practice, curate and the Learn
Obsidian plugin. The vault contract owns note structure and durable learning progress.
Pi conversations provide session history, not a second progress database. Learning remains
Priority 3; phone practice remains Priority 4 under [PLAN.md](../../PLAN.md).

The entry is a topic or existing note, with optional sources. Sessions may suggest a short
review without notifications. Teaching updates concepts; reusable claims receive learner
review at close. Real sessions, not a predetermined UI wishlist, choose further work.
