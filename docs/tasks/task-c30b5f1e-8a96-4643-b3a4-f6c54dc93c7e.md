# Import the first real Health export

## Outcome

The operator's Apple Health history is in the `health` capability and readable by agents.

## Acceptance

- Done 2026-11-19: `tools/service-runner.sh start health` started it and `GET /ready` answers 200.
- Done 2026-11-19: `health import` of a 121 MB export read 5,338,625 records and stored 43,182
  daily values from 2016-06-11 to 2026-11-19 in 6.4 s. `health metrics` lists 21 keys across
  sleep, activity, heart and body.
- Open: `tools/service-runner.sh install-persistence health`, so the service survives a reboot.
- Open: an agent session reads `GET /api/summary` through the agent gate. This needs a new
  session, because the MCP server lists capabilities when it starts.

The first real import found two sleep bugs, both fixed with tests: naps counted as the night,
and a night split at midnight. A sleep session now belongs to the night its midpoint falls in
(20:00 to 12:00), and a nap is left out.
