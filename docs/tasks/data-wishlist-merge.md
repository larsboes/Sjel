# Merge duplicate wishes explicitly

## Outcome

Merge duplicate wishes explicitly through the existing owner, with implementation and live acceptance recorded separately.

## Acceptance

- Add a reviewed merge action rather than marking a duplicate given away.
- Preserve target configuration, price ceiling, deadline, dated source prices and alias/provenance so alerts and alternative-group budgets remain correct.
