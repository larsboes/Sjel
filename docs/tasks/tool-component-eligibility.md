# Gate deployment by adoption status

## Outcome

Reference snapshots cannot become active because they happen to be installed.

## Acceptance

- Enforce ownership/native-approval eligibility at install/deploy, including wildcard profiles.
- Keep unknown and reference-only units inactive; reconcile prefix semantics across adapters.
- Audit application/account discovery without activating retained Matt or Anatomy snapshots.
