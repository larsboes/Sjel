# System tools

A general skill for discovering command-line tools and using their own help, manual pages, and local version output instead of guessing flags. It contains no workstation paths or user-specific command inventory.

## Use

Use it for operating-system commands such as package managers, process tools, networking, files, and monitoring. For project-specific operations, follow that project's own documentation or dedicated skill.

## Activate

```sh
./tools/packs-pi deploy system-tools
./tools/packs-claude deploy system-tools
./tools/packs-codex deploy system-tools
```
