# Accept a reviewed TestFlight build

## Outcome

Accept a reviewed TestFlight build with repeatable evidence and no implicit deployment or publication approval.

## Acceptance

- Obtain separate owner signing/provisioning authorization, retain identities in Keychain and complete privacy/export declarations.
- Install through TestFlight on a physical phone, pair to a synthetic test node and complete a supported flow.
- Use neither household credentials nor private data in review access, release assets or screenshots; archive preparation alone is not TestFlight acceptance.
