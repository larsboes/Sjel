## Boundaries

Coding harnesses select web-research but not vault/learning skills. Pi keeps its fuller selection.
Retained Matt and Anatomy snapshots remain reference-only and held off runtime. Their source
availability is not adoption. Ponytail's exception is closed; no repetition hook is planned.
Claude Security's proprietary workflow cannot be ported; the separately reviewed MIT action is
also not adopted. Use the existing checkout reviewer with an explicit security brief.

M1/M2 probes did not establish a reasoning gain; existing guidance stays the baseline. M3–M6
require observed gaps before any adaptation. Content-pinned screening does not approve native
activation. Material permission, execution, egress or licence changes need re-review.
