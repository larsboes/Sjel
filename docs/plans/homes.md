# Homes

Household deployment repositories own their configuration and operating notes. Sjel reads explicit interfaces and adds clients only for concrete consumers. Instance facts stay private; observations about other people remain c2.

## Open

## Boundary

Archived Home Assistant, router and DNS clients are reference material, not active dependencies.
Promotion requires a consumer and an access-contract review. A household repository does not need
a Sjel port before its own cleanup. Credentials stay outside documents and prompts.
