# v0.1.0

## Changes

- The Mac app and the iPhone app render the same GPUI views. NSH is retired.
- Shared GPUI cards, badges and toggles come from Ely components.
- Note rename moves the file, rewrites `[[links]]` and reverts on Esc or blur; the phone keeps titles
  read-only.
- One branded Sjel app holds Full Disk Access, with a drag-to-grant setup.
- Command-policy autonomy covers the active checkout and session scratch only.

## Breaking changes

- The per-root command-policy configuration is gone. A machine config can only narrow the
  project scope.
- A note title cannot contain `#`, `|`, `[` or `]`.

## Upgrade

1. Install the DMG, or run `install.sh` for the CLI.
2. Grant Full Disk Access to the one **Sjel** entry, then run `sjel fda-launcher migrate`.

## Known limitations

- Six tasks remain in verify: four blocked, and two that wait on unfinished dependencies.
- On the phone, the calendar week strip, the Projects toolbar and the editor hints do not yet fit
  the screen (`gpui-phone-polish`).
- The phone exposes no accessibility tree.
