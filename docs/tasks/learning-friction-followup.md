# Select learning improvements from real use

## Outcome

Select learning improvements from real use through the existing owner, with implementation and live acceptance recorded separately.

## Acceptance

- Map each selected control to pilot friction and observable acceptance before implementation; rejected or unobserved candidates are not automatically built.
- Review streaming component rebuilds/scroll retention, credential-aware model filtering, shared Pi/model-list startup, graph-node note navigation, file/image/dictation input and collapsed thinking.
- Specify concurrent edits, duplicate-note prevention, review selection and persistence fields before adding them; per-claim due evidence needs a vault-convention decision and must remain separate from note maturity.
- Keep pedagogy in teach/practice and governed access in obsidian-access; do not introduce a second learning app, capability, graph database or durable transcript owner.
